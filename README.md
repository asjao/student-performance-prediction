# Student Performance Prediction

A machine learning project focused on predicting student academic performance using both regression and classification approaches.

This project was developed as an individual university project for the **Machine Learning** course at the **University of Sarajevo – Faculty of Science**.

## Project Overview

The dataset contains information about high school students, including demographic information, study habits, attendance, parental support, extracurricular activities, and academic performance.

The project addresses two related tasks:

- **Regression** – predicting student GPA
- **Classification** – predicting student grade class

## Workflow

The project covers the main stages of a basic machine learning workflow:

- Data loading and exploration
- Statistical analysis
- Data preprocessing
- Categorical feature encoding
- Feature correlation analysis
- Train/test splitting
- Feature scaling
- Model training
- Model evaluation
- Comparison of multiple approaches
- Analysis of overfitting and model performance

## Models

The following approaches were implemented and compared:

- Linear Regression
- Polynomial Regression
- Multinomial Logistic Regression
- Multilayer Perceptron (MLP) Neural Network

## Technologies

- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **scikit-learn**
- **Jupyter Notebook / Google Colab**

## Evaluation

Regression models were evaluated using error metrics such as mean absolute error and mean squared error.

Classification models were evaluated using:

- Accuracy
- Confusion matrices
- Training vs. test performance
- Overfitting analysis

The best classification results were obtained using polynomial regression-derived classification and the MLP neural network, both reaching approximately **77.5% test accuracy**.
